# Application Folder

- page.tsx supplies Ribaal-specific page metadata and renders RibaalHome.
- RibaalHome.tsx contains the complete client-side experience, accessible interactions, Lenis lifecycle and GSAP ScrollTrigger timelines.
- Ribaal.module.css owns all Ribaal presentation, sticky layouts, responsive art direction and reduced-motion rules.
- layout.tsx and globals.css are deliberately minimal and contain no legacy Shop From Bharat or globe runtime.
- icon.svg reuses the original Ribaal monogram as the browser/site icon.
